The shared failure reader carries what a surface needs to pick its controls: whether the request got no answer (`isNotAnswered`) and the route's name for the case (`kind`), on both `describeRequestFailure` and `HttpError`. A server sentence that ends "If this persists, report a bug." counts as asking for a bug report whatever comes before it, and `REPORT_A_BUG_ENDING` is exported for the surfaces that build their own sentence.
