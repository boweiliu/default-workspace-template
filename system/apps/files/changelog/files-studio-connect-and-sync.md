Files says how each synced folder stands as Imbue Studio reports it, and, inside the Imbue Studio app, connects a file or folder with Studio's own picker.

- A synced folder's state comes from Imbue Studio on the computer instead of a guess made by comparing names on both sides. While it syncs, the circular arrows on its icon turn, and its tooltip reads "Syncing with Kims-Mac" over how far along it is ("25% done"); once it settles it reads "Up to date with Kims-Mac"; a sync that stopped shows the orange alert, its tooltip ("Sync with Kims-Mac stopped" over the first two lines of Studio's reason) and the folder itself say why, and the folder points to retrying it in Imbue Studio; a sync Imbue Studio has switched on but isn't running shows the same alert and reads "Sync with Kims-Mac isn't running"; a sync switched off in Studio leaves the folder a live one. A copy whose computer is asleep, or whose Imbue Studio is closed, is greyed out and reads "Kims-Mac isn't answering" rather than a guess.

- An empty synced folder that is syncing says so, and how far along it is, in place of "Empty".

- The sidebar, and the folder you have open, keep up with Imbue Studio while a Files window is on screen: they check every few seconds while a folder is syncing and every 15 seconds otherwise, and right away when the window comes to the front. A file you add on your computer shows up in the open folder without leaving it. However many Files windows are open, your computers are asked at most once every couple of seconds, and not at all while no Files window is on screen. A computer that is asleep, or whose Imbue Studio is closed, shows its shares as not answering instead of the whole list failing.

- In the Imbue Studio desktop app, Connected ends in "Connect a file or folder…". It opens Studio's own file picker on your computer; the file or folder you pick is shared read-only, Studio opens its settings so you can allow changes or keep a synced copy, and the list here shows it as soon as Studio has shared it. A plain browser, a phone, or a share link has no picker to open, so the entry is not shown there.
